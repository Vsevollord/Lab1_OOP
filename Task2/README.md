# Лабораторная 1 — Задание 2: Лабиринт (генерация и поиск маршрута)

Консольное приложение на C++, реализующее модель прямоугольного лабиринта:
генерацию связного (идеального) лабиринта и поиск маршрута между клетками.

## Содержание

- Назначение
- Архитектура
- Классы и функции
- Тесты
- Принятые решения

---

## Назначение

Программа демонстрирует:

- **параметрический полиморфизм** — `Maze<T>` и шаблонные алгоритмы;
- **отделение слоёв** — предметная область, хранение, алгоритмы, вывод, демо;
- **изменяемое правило** — допустимость перехода передаётся параметром `Rule`,
  а не зашита в алгоритм;
- **инварианты структуры** — размер ≥ 2×2, проход только между соседями,
  проход хранится один раз;
- **модель владения** — значение (`std::vector<Cell>`, `T` по значению),
  без сырых указателей;
- **генерацию идеального лабиринта** (DFS + backtrack);
- **поиск кратчайшего маршрута** (BFS);
- **текстовое представление** с метками `S` (старт), `E` (финиш), `*` (путь).

## Архитектура

```
┌─────────────── Предметная область ───────────────┐
│  Pos {row, col}        Room {bool trap}          │
└──────────────────────────────────────────────────┘
                       │ T = Room
┌────────────── Структура хранения ────────────────┐
│  Maze<T>                                          │
│    Cell { T data; bool right, down; }            │
│    vector<Cell> cells                             │
│    addPassage / hasPassage / openNeighbors        │
│    passageCount / clearPassages                   │
└──────────────────────────────────────────────────┘
                       │ шаблонные алгоритмы
┌────────────────── Алгоритмы ─────────────────────┐
│  generateMaze<T>            (DFS + backtrack)     │
│  findPath<T, Rule>          (BFS + правило)       │
│  countReachable / isConnected / isPerfect         │
└──────────────────────────────────────────────────┘
                       │
┌────────────────── Вывод ─────────────────────────┐
│  mazeToString<T>                                  │
└──────────────────────────────────────────────────┘
                       │
┌─────────────── Демонстрация / тесты ─────────────┐
│  demo(), test*(), main()                          │
└──────────────────────────────────────────────────┘
```

## Классы и функции

### `Pos` — позиция клетки

```cpp
struct Pos { int row, col; };
```

Перегружены `==` и `!=`. Это значение-координата, не объект с поведением.

### `Room` — содержимое клетки (пример `T`)

```cpp
struct Room { bool trap = false; };
```

`Maze` про `Room` ничего не знает — это параметр шаблона.

### `Maze<T>` — структура хранения

Хранит клетки в плоском `std::vector<Cell>` (индекс `row*cols + col`).
Проход хранится **один раз** — флагами `right`/`down` у верхней/левой клетки
(нормализация через `swap`).

| Метод | Описание |
|---|---|
| `Maze(int r, int c)` | `r,c >= 2`, иначе `std::invalid_argument` |
| `getRows()`, `getCols()`, `cellCount()` | размеры |
| `inside(Pos)` | внутри ли лабиринта |
| `at(Pos)` | доступ к `T` (бросает `std::out_of_range`) |
| `neighbors(Pos)` | все соседи по стороне |
| `addPassage(a, b)` | добавить проход (только между соседями) |
| `hasPassage(a, b)` | есть ли проход (симметрично) |
| `openNeighbors(Pos)` | соседи, с которыми есть проход |
| `passageCount()` | число проходов |
| `clearPassages()` | сбросить все проходы |

### Алгоритмы

```cpp
template <typename T>
void generateMaze(Maze<T>& maze, unsigned seed);
```
Рандомизированный **DFS + backtrack** — идеальный лабиринт
(каждая клетка посещается ровно раз, `V-1` проходов, связность).

```cpp
template <typename T, typename Rule>
std::vector<Pos> findPath(const Maze<T>& maze, Pos start, Pos finish, Rule canMove);
```
**BFS** — кратчайший путь в невзвешенном графе. `Rule` — правило допустимости
перехода (функтор или лямбда). `parent` хранит предшественника для
восстановления пути.

```cpp
template <typename T> std::vector<Pos> findPath(const Maze<T>&, Pos, Pos);
```
Обёртка с правилом `AnyMove` (любой ход разрешён).

```cpp
template <typename T> bool isConnected(const Maze<T>&);
template <typename T> bool isPerfect(const Maze<T>&);
```
Связность — обходом из `(0,0)`. Идеальность = связность + `V-1` проходов
(критерий дерева).

### Вывод

```cpp
template <typename T>
std::string mazeToString(const Maze<T>&, Pos start, Pos finish,
                         const std::vector<Pos>& path);
```

ASCII-рамки, метки `S`/`E`/`*`. Не зависит от `T`.


## Тесты

Тесты запускаются автоматически в `main()` **до** демонстрации.
В конце печатается:

```
Passed: N, failed: M
```

| Функция | Покрытие |
|---|---|
| `testCreate` | валидация размеров (`1×5`, `3×0` → исключения), границы `inside` |
| `testNeighbors` | число соседей (угол/край/центр), исключение вне лабиринта |
| `testPassages` | симметричность, вертикальные, отсутствие дубликатов, диагональ/та же клетка/вне лабиринта → исключения, `clearPassages` |
| `testData` | `T = int`, `T = std::string`, исключение вне лабиринта |
| `testGenerate` | идеальность на разных размерах и seed, повторная генерация |
| `testProperties` | пустой несвязен; 3 прохода в 2×2 — идеальный; 4-й — цикл |
| `testFindPath` | валидный путь, `start == finish`, нет пути, кратчайший в цикле, правило-фильтр блокирует клетку, исключение вне лабиринта |
| `testOutput` | точное совпадение ASCII-вывода |

`isValidPath` проверяет, что каждая пара соседних клеток пути соединена
проходом, а концы совпадают с заданными — тесты не доверяют алгоритму.

## Принятые решения

| Решение | Почему |
|---|---|
| Плоский `vector<Cell>` | кэш-локальность, `O(1)` доступ, без лишних аллокаций |
| Проходы — флаги `right`/`down`, один раз | компактно, исключает рассогласование |
| Шаблон `Maze<T>` | параметрический полиморфизм, типобезопасность, zero-cost |
| Генерация — DFS + backtrack | прост, идеальный лабиринт, легко обосновать |
| Поиск — BFS | кратчайший путь в невзвешенном графе |
| Правило хода — шаблонный `Rule` | zero-cost, OCP: новое правило не меняет `findPath` |
| Владение — значение | RAII, нет сырых указателей и утечек |
| Идеальность = связность + `V-1` | `O(V+E)`, математически эквивалентно дереву |
| `seed` параметром | воспроизводимые тесты |
| Вывод — отдельная функция | SRP, тестируемость по точной строке |
